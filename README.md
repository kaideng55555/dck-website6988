# DCK Website

A modern, responsive website built with HTML, CSS, and JavaScript.

## Features

- 🎨 Modern and clean design
- 📱 Fully responsive (mobile, tablet, desktop)
- ⚡ Fast and lightweight
- 🚀 Smooth animations and transitions
- 📝 Contact form with validation
- 🎯 Smooth scrolling navigation

## File Structure


## How to Use

1. **View the website locally:**
   - Simply open `index.html` in your web browser
   - Or use a local server like:
     ```bash
     python -m http.server 8000
     ```
     Then visit `http://localhost:8000`

2. **Deploy the website:**
   - Upload all files to your web hosting service
   - Or use GitHub Pages (enable it in repository settings)

## Sections

- **Home**: Hero section with call-to-action
- **About**: Information about the company with feature highlights
- **Services**: Service offerings
- **Contact**: Contact form for inquiries

## Customization

- **Colors**: Edit CSS variables in `styles.css` (`:root` section)
- **Content**: Modify text in `index.html`
- **Functionality**: Adjust behavior in `script.js`
